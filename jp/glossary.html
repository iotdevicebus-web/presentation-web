用語の定義 (A-Z アルファベット順)

Universal IoT Bus 用語の定義辞書

アルファベット順（A to Z）一覧 ＆ やさしい解説表

当プレゼンテーション・技術資料で使用されているハードウェア・ソフトウェア・セキュリティ用語をアルファベット順（A〜Z）に整理し、簡潔でわかりやすい解説をまとめました。

英語表記 (Term) 解説 (Explanation)
Antigravity
Agentic Coding AI Assistant
開発AI環境 		【アンチグラビティ (開発AIエージェントプラットフォーム)】
Google DeepMindチームが開発した高度なAgentic Coding AIアシスタント環境。複雑なコード設計、仕様生成、自動診断、テスト実行、Webポータル構築までを一元支援します。
ASIC
Application Specific Integrated Circuit
半導体量産 		【特定用途向けIC】
UIBの通信制御など、特定の目的のためだけに最適化して製造される専用の量産型半導体チップ。大量生産により単価を数十円〜数百円に抑えられます。
Circuit Breaker
Physical Power Gating
物理遮断 		【遮断器 / 緊急防衛回路】
外部からの不正アクセスや電気的な過電流・異常信号を検知した際に、100ミリ秒（0.1秒）未満で物理的に回路や通信電源を断ち切り、システム全壊を防ぐ防衛装置。
Cold Start 5.0s
Fast Boot Sequence
高速起動 		【コールドスタート（超高速起動）】
システムの電源が完全に切れていた無電化状態から、センサ異常や緊急事態を検知した瞬間にわずか5.0秒以内で全システムが起動し、通信・制御を完了する技術。
Diagnostics
System Self-Diagnostics
自己診断 		【ダイアグノスティクス（自動診断システム）】
ハードウェア基板やソフトウェア通信の健康状態（異常電圧、データエラー率、通信遅延）をリアルタイムで自動計測・自己診断する安全監視機能。
Dual-Track Strategy
Commercial & Public Model
事業戦略 		【デュアルトラック（二元推進）戦略】
防災・医療などの「社会貢献・公共インフラ推進」と、製品販売やライセンスによる「民間B2B事業」の2つの軸を同時に走らせ、世界標準化を達成する戦略。
Edge Device
Edge Node Hardware
現場端末 		【エッジデバイス（現場端末）】
センサーやカメラ、制御モーターなど、データが発生する現場（現場最前線）に設置される末端のハードウェア機器。
FPGA
Field Programmable Gate Array
試作用半導体 		【書き換え可能半導体】
出荷後でもプログラミングによって内部の電気回路構成を自由に変更・書き換えできる実験・プロトタイプ検証用の半導体チップ。
Gemini AI
Google Multimodal AI
AI統合 		【Gemini AI (ジェミニ エーアイ)】
Googleが開発した高度なAIモデル。本プロジェクトではエッジ端末の24時間異常監視、コード自動生成、および未知のサイバー攻撃に対するパッチ自動生成を担います。
Hardware RoT
Root of Trust
セキュリティ 		【ハードウェア信頼の起源】
シリコンチップの製造時に直接刻み込まれる「改ざん不能な身分証明書」。偽物基板や不正プログラムの起動をハードウェアレベルで物理的に拒否します。
HIFU Beamforming
High-Intensity Focused Ultrasound
先端医療 		【強力超音波(HIFU)ビームフォーミング】
イージス艦のレーダー原理を応用し、複数の超音波の波のタイミング（位相）を正確に合わせることで、メスを入れることなく体内の患部へピンポイントでエネルギーを集中させる医療技術。
Host System
Central Server & Cloud
基幹システム 		【ホストシステム】
エッジデバイスから送られてくる全データを集約・分析し、全体の動作命令を発行するクラウドやサーバー側の基幹システム。
Interrupt
Priority Signal Interrupt
割り込み制御 		【インタラプト（緊急割り込み処理）】
センサーからの急な警報や異常信号が入った際、実行中の通常処理を一時中断し、最優先で緊急防衛プログラムを実行させるハードウェア信号メカニズム。
IoT Cloud Server
Cloud Orchestration
クラウド基盤 		【IoT クラウドサーバー】
全世界のエッジ端末から送られてくるデータを大規模に集約・分析し、Gemini AI連携や全自動ダッシュボード表示を提供するクラウド側の基幹サーバー。
IrDA
Infrared Data Association
国際通信規格 		【IrDA (赤外線通信国際規格)】
ノートPCや携帯電話、医療機器で広く世界標準となった赤外線近距離無線通信規格。発案者の北角権太郎が元・米国IrDA会長としてグローバル普及を主導。
LL Grammar Zero-Parse
Zero-Parse Grammar
プロトコル解析 		【LL文法 ゼロパース解析】
受信したデータを左から順に読むだけで意味が即座に理解できる通信構造。データ解釈の計算負荷（パース）をゼロにし、バッファ溢れ（ハッキング）を構造的に防ぎます。
Pre-Seed / Seed Funding
Early Stage Investment
資金調達 		【プレシード / シード調達】
起業・プロジェクトの極めて初期段階（プロトタイプ完成や実証実験）において、最初の実機やデータを獲得するために行う初期資金調達。
PUF
Physical Unclonable Function
シリコン指紋 		【物理複製不可機能 (シリコン指紋)】
半導体の製造過程で生じる超微細な個体差を利用して作る暗号鍵。人間の「指紋」のように世界に1つだけで、複製や暗号解読が不可能。
RISC-V
Open Architecture CPU
オープンCPU 		【リスク・ファイブ (オープンCPU指令集)】
世界中だれでも高額な特許・ライセンス料を支払うことなく自由に利用・カスタマイズできる、オープンソース型のCPU設計規格。
RTL
Register Transfer Level
回路記述コード 		【RTL（Register Transfer Level / 論理回路記述言語）】
VerilogやVHDLなどの言語を使って、半導体チップ内部のデータ移動と論理回路の動作を詳細にプログラミング記述したハードウェア設計コード。
Silicon Design
Semiconductor Layout
半導体設計 		【シリコンデザイン（半導体回路設計）】
微細な半導体ウエハ上にトランジスタや論理回路をレイアウトし、独自のICチップやSoCを作り上げる高度なハードウェア設計プロセス。
SoC
System on Chip
システム集積IC 		【システム・オン・チップ】
CPU、メモリ、通信回路、入出力インターフェースなど、システム全体に必要な機能を1つの半導体チップ上に集約・統合した超小型IC。
Stress Test
Extreme Load Testing
負荷耐性試験 		【ストレステスト（限界負荷試験）】
極限の高温・過酷な電圧変動・大量の攻撃トラフィックなどを意図的に与え、ハードウェアやシステムの限界耐久性と堅牢性を検証するテスト。
ultra-low power
10μA Micro Standby
超低消費電力 		【超低消費電力 (10μA待機)】
待機電流をわずか10マイクロアンペア（極小）に抑える回路設計。小型電池や環境発電（ソーラー）だけで数年〜10年以上連続稼働可能。
Universal IoT Bus (UIB)
Open Edge Infrastructure
コア規格 		【ユニバーサル・アイオーティー・バス】
多彩なセンサーや制御機器を「レゴブロック」のように直感的に接続し、一元制御できるオープンな次世代通信・制御インフラ規格。
Universal Reference Kit
Hardware Reference Kit
実機検証基盤 		【ユニバーサル・リファレンスキット】
通信特化の「Aボード」とバス集約の「Bボード」からなる、UIB規格の動作検証・PoC開発をだれでも即座に行える高品質ハードウェア実験キット。
